    Leaderboard¶

    Shortcut detection and mitigation methods, each scored by the same code on the same benchmark with planted shortcuts of known strength. Four tracks, scored separately: an embedding method and an image method are never ranked against each other.

    Have a method? Add it in one folder and one pull request: how to submit. CI scores it on the benchmark and your entry appears here, with your name and paper, when it is merged.

    Separate from the paper's audit

    The leaderboard measures methods on synthetic benchmarks. It does not change what conditional_audit, the package's calibrated test, reports. The benchmark's rules and metrics are on the tracks page.

    Embedding detection¶

    Given embeddings E, an attribute A and a task label Y, score whether E carries A beyond what Y explains. Null datasets have A correlated with Y but no extra attribute signal, so a method that only finds the correlation scores 0.5.
